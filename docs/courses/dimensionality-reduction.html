Dimensionality Reduction

PCA, t-SNE, and UMAP — theory and practice

Learning objectives

After completing this module you should be able to:

  1. Explain PCA as a linear projection that maximises retained variance, and compute it via eigendecomposition of the covariance matrix.
  2. Choose the number of principal components based on scree plots and cumulative explained variance.
  3. Describe the perplexity parameter of t-SNE and its effect on cluster spacing.
  4. Contrast the geometric assumptions of PCA, t-SNE, and UMAP, and select the appropriate method for a given task.
  5. Produce and interpret interactive scatter plots from each embedding.

Motivation

High-dimensional data — genomic arrays, audio spectrograms, spectral images — cannot be visualised directly. Dimensionality reduction methods project data into a low-dimensional space (typically 2D or 3D) while preserving structure that is relevant to the question at hand. The three methods covered here each define “preserving structure” differently, which leads to qualitatively different results on the same data.

Dataset

All examples use the handwritten digits dataset from scikit-learn (a downsampled version of the MNIST dataset). Each observation is an 8×8 grayscale image of a handwritten digit, flattened to 64 features. The dataset contains 1 797 images across 10 classes (digits 0–9).

import numpy as np
import pandas as pd
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler

digits = load_digits()
X, y = digits.data, digits.target          # shape: (1797, 64)
labels = [str(d) for d in y]

print(f"Samples: {X.shape[0]}  |  Features: {X.shape[1]}  |  Classes: {len(np.unique(y))}")

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
Samples: 1797  |  Features: 64  |  Classes: 10

Principal Component Analysis (PCA)

Theory

PCA finds an orthonormal basis for \(\mathbb{R}^p\) such that projecting the data onto the first \(k\) basis vectors (principal components) maximises retained variance. The principal components are the eigenvectors of the sample covariance matrix \(\hat{\Sigma} = \frac{1}{n-1} X^\top X\), sorted by decreasing eigenvalue.

Formally, the \(j\)-th principal component direction \(\mathbf{w}_j\) solves:

\[\mathbf{w}_j = \arg\max_{\|\mathbf{w}\|=1,\, \mathbf{w} \perp \mathbf{w}_{1:j-1}} \mathbf{w}^\top \hat{\Sigma} \mathbf{w}\]

In practice this is computed via SVD: \(X = U \Sigma V^\top\), where the columns of \(V\) are the principal component directions.

Key properties: - PCA is a linear transformation — it cannot capture nonlinear structure. - The projection is globally optimal for variance preservation under the Frobenius norm (Eckart–Young theorem). - Principal components are uncorrelated by construction. - PCA is sensitive to feature scale → always standardise features first.

Explained variance

from sklearn.decomposition import PCA
import plotly.graph_objects as go

pca_full = PCA(n_components=50)
pca_full.fit(X_scaled)
cumvar = np.cumsum(pca_full.explained_variance_ratio_) * 100

fig = go.Figure()
fig.add_trace(go.Bar(
    x=list(range(1, 51)),
    y=np.diff(np.concatenate([[0], cumvar])),
    name="Individual component",
    marker_color="#adb5bd",
    opacity=0.7
))
fig.add_trace(go.Scatter(
    x=list(range(1, 51)),
    y=cumvar,
    mode="lines+markers",
    name="Cumulative",
    marker=dict(size=5, color="#2a7f7f"),
    line=dict(color="#2a7f7f", width=2)
))
fig.add_hline(
    y=90,
    line_dash="dash",
    line_color="#868e96",
    annotation_text="90 %",
    annotation_position="right"
)
fig.update_layout(
    xaxis_title="Principal component",
    yaxis_title="Explained variance (%)",
    template="simple_white",
    height=380,
    legend=dict(orientation="h", y=1.1)
)
fig.show()

The first principal component captures the largest single source of variation; by ~20 components roughly 90% of total variance is retained. Beyond that, each additional component contributes marginally.

2D PCA projection

import plotly.express as px

pca2 = PCA(n_components=2)
X_pca2 = pca2.fit_transform(X_scaled)

df_pca = pd.DataFrame({
    "PC1": X_pca2[:, 0],
    "PC2": X_pca2[:, 1],
    "Digit": labels
})

fig = px.scatter(
    df_pca, x="PC1", y="PC2", color="Digit",
    color_discrete_sequence=px.colors.qualitative.D3,
    opacity=0.65,
    template="simple_white",
    height=480
)
fig.update_traces(marker=dict(size=5))
fig.update_layout(
    xaxis_title=f"PC1 ({pca2.explained_variance_ratio_[0]*100:.1f}% variance)",
    yaxis_title=f"PC2 ({pca2.explained_variance_ratio_[1]*100:.1f}% variance)",
    legend_title_text="Digit"
)
fig.show()

Notice that PCA partially separates some digits (e.g. 0 and 1) but many classes overlap. This is expected: PCA finds directions of maximum global variance, not directions that maximise class separation. Linear separability is not guaranteed.

t-SNE

Theory

t-SNE (t-distributed Stochastic Neighbour Embedding; van der Maaten & Hinton, 2008) minimises the Kullback–Leibler divergence between two probability distributions:

  • \(p_{ij}\): pairwise similarities in the high-dimensional space, modelled with Gaussian kernels whose bandwidth is set so that each point has a fixed perplexity (roughly the number of effective nearest neighbours).
  • \(q_{ij}\): pairwise similarities in the low-dimensional space, modelled with a heavy-tailed Student-t kernel (df = 1), which alleviates the crowding problem.

Key properties and caveats: - t-SNE is nonlinear and captures local structure well. - Cluster sizes and inter-cluster distances in a t-SNE plot are not interpretable — they are artefacts of the optimisation, not data properties. - Results are stochastic; use random_state for reproducibility. - perplexity (default 30) controls the neighbourhood size. Typical range: 5–50. Larger datasets may benefit from larger values. - t-SNE does not produce a reusable projection — new points cannot be embedded without re-running the algorithm on the full dataset.

from sklearn.manifold import TSNE

tsne = TSNE(n_components=2, perplexity=30, max_iter=1000, random_state=42)
X_tsne = tsne.fit_transform(X_scaled)

df_tsne = pd.DataFrame({
    "tSNE-1": X_tsne[:, 0],
    "tSNE-2": X_tsne[:, 1],
    "Digit": labels
})

fig = px.scatter(
    df_tsne, x="tSNE-1", y="tSNE-2", color="Digit",
    color_discrete_sequence=px.colors.qualitative.D3,
    opacity=0.65,
    template="simple_white",
    height=480
)
fig.update_traces(marker=dict(size=5))
fig.update_layout(legend_title_text="Digit")
fig.show()

t-SNE produces clearly separated clusters for most digit classes. The digit 1 and 7 clusters are close, reflecting genuine visual similarity between those characters. However, the spatial arrangement of clusters across the plot is arbitrary — do not interpret proximity between clusters as meaningful.

UMAP

Theory

UMAP (Uniform Manifold Approximation and Projection; McInnes et al., 2018) is grounded in Riemannian geometry and algebraic topology. It constructs a fuzzy topological representation of the high-dimensional data by modelling the manifold as a weighted \(k\)-nearest-neighbour graph, then optimises a low-dimensional layout that preserves the graph structure.

Key advantages over t-SNE: - Better preservation of global structure alongside local structure. - Significantly faster for large datasets. - Produces a reusable transform that can embed new points. - More stable to hyperparameter choices.

Key hyperparameters: - n_neighbors (default 15): controls the local neighbourhood used to estimate the manifold. Larger values → more global structure preserved. - min_dist (default 0.1): controls how tightly points are packed in the embedding. Smaller values → tighter clusters.

try:
    import umap

    reducer = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=42)
    X_umap = reducer.fit_transform(X_scaled)

    df_umap = pd.DataFrame({
        "UMAP-1": X_umap[:, 0],
        "UMAP-2": X_umap[:, 1],
        "Digit": labels
    })

    fig = px.scatter(
        df_umap, x="UMAP-1", y="UMAP-2", color="Digit",
        color_discrete_sequence=px.colors.qualitative.D3,
        opacity=0.65,
        template="simple_white",
        height=480
    )
    fig.update_traces(marker=dict(size=5))
    fig.update_layout(legend_title_text="Digit")
    fig.show()

except ImportError:
    print("umap-learn not installed.  Run:  pip install umap-learn")

Comparison

Property PCA t-SNE UMAP
Transformation Linear Nonlinear Nonlinear
Preserves Global variance Local neighbourhood Local + global topology
Cluster distances interpretable? Yes (variance) No Partially
Embeds new points? Yes No Yes (with transform)
Speed (large \(n\)) Fast Slow Fast
Deterministic? Yes No (stochastic) No (stochastic)
Key hyperparameter n_components perplexity n_neighbors, min_dist

Practical guidance: Use PCA for a quick sanity check and when linearity is defensible. Use t-SNE or UMAP for exploratory cluster visualisation. Use UMAP when you need to embed new data or when the dataset is large. Never use t-SNE cluster layout for quantitative comparisons.
